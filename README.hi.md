टाइपस्क्रिप्ट में निर्मित एक निश्चित (डिटरमिनिस्टिक) वोकल इंस्ट्रूमेंट इंजन। यह योज्य संश्लेषण (एडिटिव सिंथेसिस), आवाज के पूर्वनिर्धारित सेटिंग्स और वास्तविक समय में वेबसॉकेट स्ट्रीमिंग का उपयोग करके संगीत नोटों से गायन की आवाज़ उत्पन्न करता है। आप इसे कीबोर्ड/एमआईडीआई के माध्यम से लाइव बजा सकते हैं, बहु-उपयोगकर्ता सत्रों में सहयोग कर सकते हैं, या संगीत नोटों को WAV फ़ाइल में बदल सकते हैं।

**स्थिति:** v1.0.3 संस्करण। स्रोत कोड अभी तक npm पर प्रकाशित नहीं किया गया है। v1.0.4 संस्करण के प्रकाशित होने तक, स्रोत कोड से ही इसे स्थापित करें (इंस्टॉलेशन के लिए [इंस्टॉल](#install) देखें)।

## यह क्या करता है।

- **एडिटिव वोकल सिंथेसिस:** हार्मोनिक आंशिक घटक + स्पेक्ट्रल एनवेलप + शोर अवशेष।
- **15 आवाज प्रीसेट:** कोकोरो टीटीएस आवाजों से प्राप्त विश्लेषण डेटा + प्रयोगशाला प्रीसेट, प्रत्येक में कई तरह की ध्वनियाँ।
- **पॉलीफोनिक रेंडरिंग:** कॉन्फ़िगर करने योग्य अधिकतम पॉलीफोनी, प्रत्येक आवाज के लिए स्थिति प्रबंधन और आवाज "चोरी" की सुविधा।
- **लाइव मोड:** कीबोर्ड या MIDI के माध्यम से नोट्स बजाएं, वास्तविक समय में वेबसॉकेट ऑडियो स्ट्रीमिंग के साथ।
- **जाम सेशन:** बहु-उपयोगकर्ता सहयोगात्मक सत्र, जिसमें होस्ट का अधिकार, प्रतिभागी की पहचान और रिकॉर्डिंग की सुविधा।
- **स्कोर इनपुट:** स्वचालित प्लेबैक के लिए एक `वोकल स्कोर` को ट्रैक में लोड करें, जो ट्रांसपोर्ट के साथ सिंक्रोनाइज़ होगा।
- **रिकॉर्डिंग और निर्यात:** लाइव प्रदर्शन को एक इवेंटटेप में कैप्चर करें, और इसे पूरी जानकारी के साथ WAV फॉर्मेट में निर्यात करें।
- **गीत और ध्वनियाँ:** ग्राफीम-टू-फोनिम पाइपलाइन, जिसमें ध्वनियों का दृश्य प्रदर्शन शामिल है।
- **कॉकपिट यूआई:** ब्राउज़र-आधारित सिंगल पेज एप्लिकेशन, जिसमें पियानो रोल एडिटर, लाइव कीबोर्ड, XY पैड, रेंडर बैंक और टेलीमेट्री शामिल हैं।
- **निश्चित:** सीडेड रैंडम नंबर जेनरेटर, समान इनपुट से पुन: प्रस्तुत करने योग्य आउटपुट।

## स्थापित करें।

पैकेज `@mcptoolshop/vocal-synth-engine` अभी तक npm पर प्रकाशित नहीं किया गया है। जब तक कि संस्करण 1.0.4 जारी नहीं हो जाता, तब तक इसे स्रोत कोड से स्थापित करें:

```bash
git clone https://github.com/mcp-tool-shop-org/vocal-synth-engine.git
cd vocal-synth-engine
npm ci
npm run build
```

किसी विशेष कमिट को किसी अन्य परियोजना में शामिल करने के लिए:

```bash
npm install github:mcp-tool-shop-org/vocal-synth-engine#<commit-sha>
```

## शुरुआत कैसे करें।

```bash
npm ci
npm run dev
```

डेवलपमेंट सर्वर `http://localhost:4321` पर शुरू होता है। कॉकपिट यूआई भी इसी पोर्ट से उपलब्ध है।

## कॉकपिट यूजर इंटरफेस।

कॉकपिट एक ब्राउज़र-आधारित सिंगल-पेज एप्लिकेशन (SPA) है, जिसमें तीन टैब हैं:

### स्कोर संपादक
- पियानो रोल: नोट्स को खींचकर बनाना, स्थानांतरित करना और आकार बदलना (C2-C6 रेंज)।
- प्रत्येक नोट के लिए नियंत्रण: गति, ध्वनि की गुणवत्ता, गहराई, कंपन, पोर्टामेंटो।
- स्वचालित ध्वन्यात्मक (phoneme) निर्माण के साथ गीत इनपुट।
- पियानो रोल के साथ सिंक्रोनाइज़ किया गया ध्वन्यात्मक लेन ओवरले।
- WAV फ़ाइल में रूपांतरण, जिसमें पूर्वनिर्धारित सेटिंग्स, बहुस्वरता (polyphony), बीज (seed) और बीपीएम (BPM) को अनुकूलित किया जा सकता है।

### लाइव मोड
- 24-कुंजी वाला क्रोमेटिक कीबोर्ड (माउस + की बाइंडिंग के साथ)
- चैनल फ़िल्टरिंग के साथ MIDI डिवाइस इनपुट
- वास्तविक समय में ध्वनि परिवर्तन (X) और सांसारिकता (Y) के लिए XY पैड
- होल्ड पैडल, वेलोसिटी/सांसारिकता स्लाइडर, वाइब्रेटो नियंत्रण
- क्वांटाइज ग्रिड (1/4, 1/8, 1/16) के साथ मेट्रोनोम
- विलंबता अंशांकन (कम/संतुलित/सुरक्षित प्रीसेट)
- प्रदर्शन रिकॉर्ड करें और रेंडर बैंक में सहेजें
- लाइव टेलीमेट्री: आवाजें, पीक dBFS, RTF, क्लिक जोखिम, WS जिटर।

### रेंडर बैंक।
- सहेजे गए रेंडर को ब्राउज़ करें, चलाएं, पिन करें, नाम बदलें और हटाएं।
- किसी रेंडर के स्कोर को वापस एडिटर में लोड करें।
- रेंडर के बीच साइड-बाय-साइड टेलीमेट्री तुलना।
- उत्पत्ति का पता लगाना: कमिट SHA, स्कोर हैश, WAV हैश।

## जाम सेशन

वेबसॉकेट (`/ws/jam`) पर मल्टी-यूजर सहयोगात्मक सेशन:

- **होस्ट अधिकार:** सेशन निर्माता ट्रांसपोर्ट, ट्रैक, रिकॉर्डिंग और क्वांटाइजेशन को नियंत्रित करता है।
- **अतिथि भागीदारी:** अतिथि किसी भी ट्रैक पर नोट्स बजा सकते हैं, लेकिन वे सेशन की स्थिति को संशोधित नहीं कर सकते।
- **ट्रैक स्वामित्व:** ट्रैक उनके निर्माता के होते हैं; केवल मालिक या होस्ट ही उन्हें संशोधित/हटा सकता है।
- **भागीदार का विवरण:** इवेंटटेप में प्रत्येक नोट इवेंट रिकॉर्ड करता है कि किसने उसे बजाया।
- **स्कोर इनपुट मोड:** स्वचालित प्लेबैक के लिए एक `VocalScore` को एक ट्रैक में लोड करें, जो ट्रांसपोर्ट के साथ सिंक होगा।
- **रिकॉर्डिंग:** सभी प्रतिभागियों के नोट्स को एक इवेंटटेप में कैप्चर करें, WAV में एक्सपोर्ट करें।
- **मेट्रोनोम:** कॉन्फ़िगर करने योग्य BPM और टाइम सिग्नेचर वाला एक साझा मेट्रोनोम।

### जाम प्रोटोकॉल

क्लाइंट `/ws/jam` से कनेक्ट होते हैं और JSON संदेशों का आदान-प्रदान करते हैं:

```
Client: jam_hello → Server: jam_hello_ack (participantId)
Client: session_create → Server: session_created (snapshot)
Client: session_join → Server: session_joined (snapshot)
Client: track_note_on/off → Server: track_note_ack
Client: record_start/stop → Server: record_status
Client: record_export → Server: record_exported (renderId)
Client: track_set_score → Server: score_status
```

## MCP सर्वर

वॉयस-सिंथ-इंजन एक MCP (मॉडल कॉन्टेक्स्ट प्रोटोकॉल) सर्वर के साथ आता है ताकि क्लाउड एजेंट और अन्य MCP क्लाइंट सीधे इंजन को कॉल कर सकें - HTTP ढांचे की आवश्यकता नहीं है। `vocal-synth-engine-mcp` बिन एंट्री (stdio ट्रांसपोर्ट) के माध्यम से बूट करें।

उपलब्ध उपकरण:

| उपकरण | उद्देश्य। |
|------|---------|
| `render_score` | एक प्रीसेट के माध्यम से एक VocalScore को रेंडर करें → बेस64 WAV + टेलीमेट्री |
| `phonemize_text` | गीत पाठ → ARPAbet PhonemeEvents (यदि `notes` प्रदान किए गए हैं तो नोट-संरेखित) |
| `list_presets` | उपलब्ध प्रीसेट आईडी की सूची (GET /api/presets के समान आकार) |
| `validate_score` | रेंडर किए बिना VocalScore JSON को पार्स करें और मान्य करें |
| `inspect_preset` | प्रीसेट मैनिफेस्ट + प्रति-टिमब्रे हार्मोनिक्स/ऊर्जा (vse-inspect --json के समान) |

इसे क्लाउड डेस्कटॉप / कोड कॉन्फ़िगरेशन में एकीकृत करें:

```json
{
  "mcpServers": {
    "vocal-synth-engine": {
      "command": "npx",
      "args": ["-y", "@mcptoolshop/vocal-synth-engine", "vocal-synth-engine-mcp"]
    }
  }
}
```

## टेस्ट

प्राथमिक परीक्षण सतह vitest है:

```bash
npm test                # Run all unit + integration tests once
npm run test:watch      # Watch mode
npm run test:coverage   # Coverage report
```

`scripts/` के अंतर्गत अतिरिक्त प्रतिगमन स्क्रिप्ट (जाम परीक्षणों के लिए एक चल रहे देव सर्वर की आवश्यकता होती है; अन्य स्टैंडअलोन हैं):

```bash
npx tsx scripts/test-jam-session.ts        # Jam session lifecycle
npx tsx scripts/test-jam-recording.ts      # Recording & export
npx tsx scripts/test-jam-collaboration.ts  # Collaboration & score input
npx tsx scripts/test-score-render.ts       # Score rendering pipeline
npx tsx scripts/test-consonants.ts         # Consonant phonemes
npx tsx scripts/test-g2p.ts                # Grapheme-to-phoneme
npx tsx scripts/test-lyrics-golden.ts      # Lyrics golden tests
npx tsx scripts/test-multi-timbre.ts       # Multi-timbre rendering
npx tsx scripts/test-noise-tail.ts         # Tail silence/noise
```

ये फ़ाइलें भविष्य में `tests/integration/` फ़ोल्डर में विटेस्ट के अंतर्गत स्थानांतरित की जाएंगी, इसलिए वे स्वचालित रूप से `npm test` कवरेज प्राप्त करेंगी।

## सुरक्षा और डेटा का दायरा

| पहलू | विवरण |
|--------|--------|
| **Data touched** | ऑडियो संश्लेषण (मेमोरी में), वेबसॉकेट कनेक्शन (लोकलहोस्ट), WAV फ़ाइल आउटपुट, स्कोर डेटा, वॉयस प्रीसेट |
| **Data NOT touched** | कोई टेलीमेट्री नहीं, कोई एनालिटिक्स नहीं, कोई क्लाउड सिंक नहीं, कोई क्रेडेंशियल संग्रहीत नहीं |
| **Permissions** | नेटवर्क: लोकलहोस्ट पर वेबसॉकेट सर्वर। डिस्क: उपयोगकर्ता द्वारा निर्दिष्ट पथों पर WAV फ़ाइल आउटपुट। |
| **Network** | केवल लोकलहोस्ट वेबसॉकेट सर्वर — कोई आउटबाउंड कनेक्शन नहीं। |
| **Telemetry** | कोई भी जानकारी एकत्र या भेजी नहीं जाती। |

भेद्यता रिपोर्टिंग के लिए [SECURITY.md](SECURITY.md) देखें।
